# ADR-03：系统 TTS 与后台朗读方案

## 状态
已定案（含移动端降级）。

## 背景
需求要求系统 TTS + 在线语音引擎、段落队列、翻页联动、通知栏控制、音频焦点与耳机拔出事件处理。

## 决策
- **桌面端**：Rust 侧桥接系统 TTS（枚举/驱动/语速/音调/完成与错误回调），并接入通知/焦点/耳机事件；朗读队列与 UI 解耦。
- **在线引擎**：HttpTTS 走 Rust HTTP + JS 沙箱（ADR-02）。
- **移动端降级**：后台朗读能力弱，采用**前台朗读**降级策略；若以移动端为目标，必须在 M0 内处置并记录结论。
- 权限最小化，仅申请朗读所需能力。

## 理由
桌面为主目标；移动端后台朗读在 Tauri/WebView 下受限，明确降级可避免范围失控。

## 后果
- 断网/切后台/焦点丢失行为需按 spec 5.8 对齐并纳入验收。
- 移动端若要求真后台朗读，需追加原生插件（超出当前范围）。
