# ADR-05：正则超时与熔断方案

## 状态
已定案。

## 背景
替换净化与规则引擎需执行用户/社区提供的正则，存在恶意回溯导致卡死风险。spec 要求超时自动禁用违规规则。

## 决策
- **引擎**：使用 Rust `regex`（线性时间，无回溯灾难）。
- **外层熔断**：在规则执行外包一层超时（默认 3000ms）；超时即中止该规则执行。
- **兜底**：对确需非 `regex` 语义的场景，置于可通过 Worker/线程硬中止的隔离执行单元。
- 违规规则自动禁用并回写，记录原因。

## 理由
线性时间引擎 + 外层超时可在不引入进程崩溃的前提下满足「3s 内终止」的验收要求。

## 后果
- 与 legado/Java 正则在语法子集上可能差异，需维护兼容子集说明（M6）。
- 超时禁用回写涉及持久化，需事务保护。
