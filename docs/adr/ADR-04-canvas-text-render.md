# ADR-04：自绘文本方案

## 状态
已定案。

## 背景
阅读器需自绘排版（中文禁则、两端对齐、分页、流式上屏），目标 10 万字逐页渲染 60fps。

## 决策
- **字符度量在 Rust 侧**：使用字体 crate（`ab_glyph` / `rustybuzz`）做字符/字形度量与断行、两端对齐、分页计算，输出页/行/字符坐标。
- **绘制在 Vue3 侧**：使用 HTML5 Canvas 2D 按坐标绘制文本、高亮与背景；翻页动画与手势在前端。
- **流式上屏**：首屏先渲染再异步续排（先显示、后继续），满足 spec 4.1.2/4.1.4。
- 中文禁则（ZhLayout）初期允许降级为普通断行 + 覆盖/滑动翻页。

## 理由
将重计算放 Rust、把绘制放 WebView Canvas，兼顾性能与前端灵活性。

## 后果
- 需维护 Rust↔前端的分页结果契约（坐标、行、字符范围）。
- 字体度量在不同平台需字体内嵌或系统字体回退，纳入风险清单。
