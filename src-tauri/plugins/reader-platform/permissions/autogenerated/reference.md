## Default Permission

Reader platform capabilities

#### This default permission set includes the following:

- `allow-platform-info`
- `allow-get-safe-area-insets`
- `allow-set-keep-screen-on`
- `allow-set-screen-orientation`
- `allow-set-cutout-mode`
- `allow-set-system-bars`
- `allow-set-system-bar-style`
- `allow-set-text-zoom`
- `allow-set-launcher-icon`
- `allow-pick-image`
- `allow-pick-font-file`
- `allow-set-reader-key-mode`
- `allow-start-background-audio`
- `allow-stop-background-audio`
- `allow-get-web-view-cookie`
- `allow-set-web-view-cookie`
- `allow-pick-books-directory`
- `allow-list-books-directory`
- `allow-scan-books-directory`
- `allow-delete-saf-documents`
- `allow-prepare-books-import`
- `allow-cleanup-saf-import`
